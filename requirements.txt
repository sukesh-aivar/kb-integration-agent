# Runtime dependencies for the Knowledge Base Integration Agent.
# Versions are pinned for reproducibility (see spec 2.3).
#
# Python version: 3.11 is the supported target for this prototype.
#   - umap-learn 0.5.6 ships prebuilt wheels for cp311 and hdbscan 0.8.38 builds
#     cleanly against numpy 1.26 on cp311 (verified at build time).
#   - 3.12 is expected to work; 3.13/3.14 are NOT supported yet because numba
#     (a umap-learn dependency) and hdbscan wheels lag the newest CPython.
#   - This resolves OPEN_QUESTIONS Q (python version) with a verified default.

# --- AWS ---
# boto3 >= 1.40 is REQUIRED for the S3 Vectors knowledge-base API
# (storageConfiguration.s3VectorsConfiguration); 1.35.x raised a
# ParamValidationError. Verified working at 1.43.114 (freq-test, 2026-10-17).
boto3==1.43.114           # S3, Bedrock, Bedrock Agent (KB), Data Automation, S3 Vectors
botocore==1.43.114

# --- Config / validation ---

# --- Tickets ---
